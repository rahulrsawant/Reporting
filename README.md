# Reporting

This is intended as a working example of a clean architecture based ASP.NET Core Web API, along with a lightweight React frontend.

The idea is a simple reporting app for investment data. Users sign in and can look up clients, funds and investors, with payments and account balances to follow.

**API:** .NET 10, ASP.NET Core Web API, Entity Framework Core, SQL Server, ASP.NET Core Identity
**UI:** React 19, TypeScript, Vite, React Router

It's still a work in progress, so expect things to change as it grows.
